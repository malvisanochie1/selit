# 📦 SelIt – Campus-Based Marketplace for Students

**SelIt** is a modern, responsive, and secure online marketplace tailored for Nigerian students to buy and sell used items within their campus communities.

Built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, SelIt empowers graduating students to quickly list items for sale and new/returning students to find affordable second-hand goods — without relying on cluttered WhatsApp groups.

## ✨ Features

- 🔐 **Secure Authentication** with Supabase
- 📸 **Image Upload & Product Listings**
- 🔍 **Explore Listings by Category or Campus**
- 💼 **Seller Dashboard & Shop View**
- ❤️ **Save Items for Later (Wishlist)**
- 📱 **Fully Responsive UI**
- ⚡ **Framer Motion Animations**
- 🛡️ **Fraud Prevention Strategies**
- 🌙 **Dark Mode (optional)**

## 🛠️ Tech Stack

| Tool                                                      | Description                                           |
| --------------------------------------------------------- | ----------------------------------------------------- |
| [Next.js 14](https://nextjs.org/)                         | React framework for server-side rendering and routing |
| [TypeScript](https://www.typescriptlang.org/)             | Type-safe JavaScript                                  |
| [Tailwind CSS](https://tailwindcss.com/)                  | Utility-first CSS framework                           |
| [Framer Motion](https://www.framer.com/motion/)           | React animation library                               |
| [Supabase](https://supabase.com/)                         | Backend-as-a-Service for auth, DB, storage            |
| [React Icons](https://react-icons.github.io/react-icons/) | Icon library                                          |

## 🧭 Pages & Routes

| Route                 | Description                           |
| --------------------- | ------------------------------------- |
| `/`                   | Homepage with featured listings       |
| `/listings`           | Explore all available items           |
| `/listings/new`       | Post a new item (sellers only)        |
| `/dashboard`          | Seller dashboard showing own listings |
| `/saved`              | View saved items (wishlist)           |
| `/login`, `/register` | Authentication pages                  |
